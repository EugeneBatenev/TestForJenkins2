# TestForJenkins2

Один минимальный набор мок-тестов для запуска из Jenkins. В отличие от первого репозитория, здесь нет разбиения на папки и не требуется переменная выбора набора.

```bash
python3 run_mock_tests.py
```

Результаты Allure сохраняются в `allure-results`; путь можно задать через `ALLURE_RESULTS_DIR`.
